# Scoring

Score each applicable dimension 0–2.

- `2` — correct and reliable
- `1` — partially correct; minor omission/verbosity but no dangerous boundary error
- `0` — incorrect or materially unsafe

Dimensions:
1. source fidelity
2. scope classification
3. fact-state discipline
4. exclusion discipline
5. conflict/supersession handling
6. compression quality
7. review clarity
8. formalization boundary

A critical fail overrides numeric score and marks the run FAIL.
