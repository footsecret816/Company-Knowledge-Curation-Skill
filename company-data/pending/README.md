# Pending Company Updates

This directory is for de-identified company-information candidates that have been surfaced for review but are **not yet formal Company Knowledge**.

Typical sources:
- approved conversation-derived company updates;
- proposed corrections;
- scope-sensitive capability changes;
- new certificate / audit / product / factory capability candidates.

Recommended organization:

```text
company-data/pending/<company-id>/...
```

Only after evidence/scope review and operator approval should a candidate be written into `company-data/packs/<company-id>/` and reflected in `company-data/REGISTRY.yaml`.
